# Shared Design for shadcn/ui Wrappers

## Scope

This document defines the shared design of wrappers for primitives generated by the shadcn/ui CLI and placed under `components/ui/`. The public shadcn/ui contract or the design document for each consuming component covers each wrapper's props, variants, display states, and usage. They are not repeated here.

## Placement and ownership boundaries

- Place implementations and stories under `components/ui/`.
- Preserve shadcn/ui's standard kebab-case filenames for CLI-generated output.
- Use the shadcn/ui defaults for aliases in `components.json` (`ui`: `@/components/ui`, `lib`: `@/lib`).
- Treat wrapper implementations as a vendor layer that the CLI can regenerate; do not edit them manually.
- Application-owned consuming components handle application state, copy, business decisions, and composition of multiple primitives.

## Customization

- Change colors through the CSS variables in [design-tokens.md](../design-tokens.md).
- Adjust component-specific appearance by passing `className` from the consumer.
- Make changes affecting the entire Tailwind scale in the project's shared theme configuration.
- When additional structure or behavior is required, compose it in an application-owned component without changing `components/ui/`.

## Storybook and tests

- Colocate `*.stories.tsx` with each wrapper and represent the variants and states exposed by shadcn/ui as stories.
- Story files are not CLI-generated, so `shadcn add --overwrite` must not overwrite them.
- Do not create wrapper-specific `*.small.test.tsx` files. Verify the contract through Storybook tests and tests of consuming components.
- Do not duplicate tests of internal behavior guaranteed by Radix UI or shadcn/ui.

## Accessibility

Use the standard Radix UI implementation for keyboard interaction, focus management, and ARIA attributes. Each application-owned component is responsible for associating labels, descriptions, errors, and loading states added by the consumer; define those associations in its individual design document.
